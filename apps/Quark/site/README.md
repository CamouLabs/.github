# Quark product page

A self-contained page for Quark, written in the same visual language as
[camoulabs.github.io](https://camoulabs.github.io): same typeface, nav, hero,
section and product panels, reveal-on-scroll behaviour, and footer — with the
palette shifted from the site's navy to Quark's indigo, and Reduce Motion
respected throughout.

It has no build step and no dependencies beyond the Google Fonts stylesheet, so
it can be opened directly:

```bash
open index.html          # macOS
python3 -m http.server   # or serve the folder
```

## Publishing it on the website

To add this page to `CamouLabs/CamouLabs.github.io`:

1. Copy this folder to `quark/` in that repository. The page then lives at
   `camoulabs.github.io/quark/`.
2. Copy `quark.png` to `apps/quark.png` there as well, so the app grid on the
   home page can use the icon at the path the other apps use.
3. On the home page, add a card to `.app-grid` alongside the existing four and a
   `Quark` entry to the footer's Apps column:

```html
<a class="app-card reveal from-scale" href="quark/">
  <img class="app-icon" src="apps/quark.png" alt="" width="60" height="60" />
  <div class="app-card-body">
    <p class="tag">Private learning</p>
    <h3>Quark</h3>
    <p>STEM practice, five minutes at a time. Privacy first, no data shared.</p>
  </div>
  <span class="app-link">Learn more ›</span>
</a>
```

4. Once Quark is on the App Store, add the icon and link to the app strip in
   [`profile/README.md`](../../../profile/README.md) so it appears on the
   organization profile with the rest of the apps.

`quark.png` is a copy of the app icon, generated by
[`.tooling/generate_app_icon.py`](../.tooling/generate_app_icon.py). Regenerate
the icon and re-copy it rather than editing the PNG by hand.
